    비즈니스 원장 관리

    임직원·계약 생성/변경·철회와 계약 원문은 내부 TLS 8443 API에서 서비스 주체 권한을 검사합니다. 이 공개 화면과 HTTP 8080에는 원장·계약 원문이 노출되지 않습니다. API 호출 형식은 운영 문서를 확인해 주세요.
