## 변경 전후 백엔드 대조

같은 임시 PostgreSQL에서 기준 커밋 `92133f8`과 작업본의 K8s 전체 시험을 돌렸다. 첫 대조에서 양쪽에 공통인 실패 30건 외에 작업본에서 가격표 기준일과 사람 권한 파일 경로 교체에 관한 실패가 발견됐다. 기준 사본의 Git 메타데이터 부재로 실패했던 배포 선언 시험 1건은 같은 커밋의 Git 참조를 연결해 재실행했을 때 통과했다.

새 가격표와 구버전 모델 단가를 함께 검증하도록 시험을 보완했다. 인증은 각 Application의 현재 설정에서 권한 파일을 찾도록 수정했다. 파일 경로 교체로 읽기 역할이 회수되면 기존 bearer와 이미 승인한 브라우저 세션 모두 다음 요청에서 거절됐다. 관련 모듈 68개가 통과했다. 독립 Application 배포 후보로 역할 검증 29개와 두 사람의 브라우저 시험·승인도 다시 통과했다.

브라우저 회귀 시험 한 건은 세션 생성 요청의 응답 전에 개인 확인 코드를 읽는 경합이 있었다. 실제 생성 응답을 받은 뒤 승인하는 순서로 고쳤고 Application 전체 350개가 다시 통과했다. 분석·임대 0건, 기존 사건 9건을 조회한 뒤 개인 권한 보완 이미지 `liveprobe/application@sha256:b7b980d83c66b97d668a5c313ab20880f49ca97881849c17ae428dc5f10cd120`을 배포했다. 두 주소에서 세 화면 폭의 탐색 시험이 통과했고 세 Deployment 모두 1/1로 준비됐다. 외부 실행기의 최근 연결 항목은 여전히 미관측이었다.
